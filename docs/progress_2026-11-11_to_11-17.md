## 4. 找出能提升分數的地方：headroom audit 與 consistent reading

- 寫了 `scripts/headroom_audit.py`，逐張臉分析問題出在哪（`2787f70`）。結果：
  - **讀值錯邊是主要問題**：模型自己的 conditioner 有時把來源臉讀錯邊，導致「加」變成幾乎沒動。
  - flow 本身沒有「完全不動」或「只動一半」的情況（0%）。
  - 逐張臉調整強度的提升不穩定，**放棄這個方向**。
- 據此做了 **consistent reading（方向一致的來源讀值）**：讀值在錯的那一邊時，把它移到正確的那一邊再編輯。**不用重訓**。
  - `editing_curves`、`comparison_table`、`models/editor.py` 都支援（`af3136b`、`ffa271a`、`c97f942`）。
  - 強度 1 時準確率 **95.0% → 98.4%**；完全編不動的臉 **3.3% → 0.3%**。
  - margin 取 0.05、0.1、0.2 結果一樣，固定用 **0.1**。

## 7. 消融實驗的工具（還沒跑）

`scripts/launch_stage2_ablation.sh`：從最終模型的 config 重建 stage-2 訓練指令，一次只改一項，再自動跑 held-out 曲線（`77dfab9`、`3a0bff5`、`2636a8a`、`3513f9d`、`99d2b2b`、`235ee9c`）。

| arm | 改了什麼 | 用途 |
|---|---|---|
| `ctrl`（加 `SEED`） | 不改，換 seed | 量 seed 之間的雜訊 |
| `nodds`、`noclip`、`noloc`、`nohead`、`oneteach`、`idcont` | 拿掉一項 loss | 決定哪些 loss 可以刪 |
| `noprior` | 拿掉方向庫 prior | 亮點 H2 的篩選 |
| `orth` | 打開正交懲罰 | 決定能不能寫「正交」 |
| `nomakeup` | 男變女時壓住口紅、化妝、耳環 | 亮點 H4（修化妝捷徑） |
| `ot`、`ot_hi` | 運輸正則（RNODE） | 亮點 H6，也可能讓編輯變快 |
| `bangsclip`、`dircond`、`truedilate`、`fixes` | 打開訓練時留著沒修的問題 | 併入 v2 |
| `custom` | 任意組合 | 確認多項 loss 一起刪也沒事 |

- `launch_chain_fix.sh` 加了 `S1_SETS`/`S2_SETS`，可以做完整訓練的消融；`--velocity_field original` 可以選（`77dfab9`）。
- **運輸正則（RNODE）已實作並驗證**：動能項和 Jacobian 項沿著 ODE 積分計算，跟解析解比對誤差約 1e-7；預設關閉（`99d2b2b`）。

### 各 baseline 在開發臉上的檢查結果

**GradCtrl：重訓版 vs. 官方權重（4 個屬性，300 張臉）**

| 屬性 | 結論 |
|---|---|
| Eyeglasses | 兩者幾乎一樣 |
| Male | 官方稍好（同準確率下 ArcFace +0.03） |
| Young | 重訓版明顯好（官方最多只到 77.5%，重訓版 96.5%） |
| Smiling | 重訓版較好 |
| 平均（約 92%） | 重訓版 0.703 vs. 官方 0.635 |

結論：移植正確，重訓版是公平的 baseline。官方的 Young 弱，是因為它的「age」定義和資料都不同。

**PluGeN：選編輯模式**

- `encoded`（只改要編輯的那個座標）比 `labels`（全部用標籤覆寫）好，準確率和 ArcFace 都較高，例如 Smiling 在強度 1.5 時 ArcFace 是 0.862 對 0.825。之後一律用 `encoded`。
- 編輯非常全域（Eyeglasses 的區域保持只有 2% 到 5%），這是 W 空間方法本身的特性。
- 準確率約 94% 時 ArcFace 0.511，是目前最弱的 baseline。

**DeltaEdit：選移除屬性的做法**

| 屬性 | 結果 |
|---|---|
| Eyeglasses、Smiling、Bangs | 很快就接近 100% |
| Male | 強度 4 時約 92%；用反義提示詞 `female face` 比較好 |
| Young | 最高只有 53%（把 `young face` 反過來），`old face` 只有 15% |

- 每個屬性各自選比較好的做法，已設成預設。
- **DeltaEdit 的論文本身沒做年齡**，所以 Young 那格會是 `--`，主表加註腳，另外做一張 4 屬性的對照表。
